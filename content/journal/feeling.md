二十年來，在我看來，什麼時候人和人的交集最多呢？出結果的時候，一切結果，結果越大，交集的量越多，結果越好，交集的質越高。中考、高考、大學畢業，每一個告一段落，在當時都曾被我看作一個「結局」，終於我的身邊似乎都是鮮花都是褒獎。

很多人歸功於，或者出於功利的角度而在語言上的，或者真正出自靈魂的，歸功於我的聰明，歸功於我的努力，歸功於我的奮鬥，歸功於我的能力，我也曾這麼想，但是我慢慢發現，即使是百分之一，在全中國十幾萬萬人中，在全世界幾十萬萬人中，也難以勝記，環球同此涼熱。至於所謂努力云云，誰不努力呢，誰能不為了自己的未來奮鬥呢，風起雲湧，滄海桑田，那麼多人，那麼多事，起起落落，哪個是一蹴而就的，哪個付出努力就一定有回報，又有多少不勞而獲？

所以歸根結底，我說，都是老天爺賞飯吃，塞翁失馬焉知非福，總是喜也是悲，悲也是喜，老天憐憫，喜是喜，悲也是喜，老天爺不悅，悲是悲，喜也是悲，禍福同因。我的中考好像不太好，考出了初中最差的成績，然而高中來看，又其實是喜非悲，我的大學層次不錯，不都取決於高考的發揮嗎，我當時沒有發燒，沒有生病，說白了不還是運氣嗎？一切皆是如此。

我的專業到底好不好呢，到底是不是符合事物發展的規律呢，總說計算機寒冬，到我報那年，還是熱門，我大一那年，我大二那年，似乎一切依舊，大三那年出的 Codex 和 Claude Code 吧，我記不清，然而一切還是正常的，只是後來才知道，是 agent hc 超發下的粉飾太平，如今，GPT-6，Claude Opus 5.5，壓得人只有五體投地的份，你說他熱門吧，傳統的測試、前端、後端哪個不是被擠壓到了難以復加的地步？

可是你說不好吧，Anna 這兩天來了北京，大談 AI，甚至 Per 也發「AI is moving from data centers into devices, transforming industries and creating entirely new opportunities」。大家都在談 Physical AI，AI in RAN，等等，在整個工業領域，真正的 AI 革命似乎剛剛升起，跟今年計算機專業的秋招前景似乎形成了十分鮮明的對比，所以你說好不好呢，其實沒什麼簡單的好壞，也沒什麼簡單的悲喜。

無非人與人運氣不同，全仰仗老天爺，雙手合十，閉上眼睛，心裡念一句阿彌陀佛，盡了人事，一切都聽天命了。
