三年多以来，我写过很多不同语言的程序，也用过大量不同的框架，尽管很多应用都是比较demo甚至是toy的级别，但在此过程中也使用了很多不同的编辑器，因此以这篇文章来进行代码编辑器或者是的评价，希望能够对初学者有一些帮助。

## DevC++

我使用的第一款IDE，当时我用他来学习C，他运行起来非常的方便，只需要简单的新建一下文件，然后再简单的去点击一个按钮，但是这其实应该是一款非常古老的软件了，后来又出现了bug，以及随着学习逐渐的深入，并不需要所谓把一个文件跑起来这样的需求。

对于一个完全入门的初学者，比如高中生，还不错，但是我不知道他的bug现在有没有修好，如果修好了，那么确实还不错，如果没有修好，那就有些不好用了。

## CodeBlocks

我使用的第二款IDE，大学开学老师推荐过的IDE，那个时候依然算是完全作为初学者，对于计算机软件没有作为一个“项目”的概念，所以开始用起来有点懵懵懂懂，但是总体来说还是非常好上手的，仍然是我最推荐的对于初学者的上手工具。

## Visual Studio

这个 IDE 我没有怎么用过，开始是要配置网络相关的库进行学习，所以下载了Visual Studio，并且我听朋友提过这个 IDE 用起来非常方便，但由于我个人的使用时间不长，不给予什么评价。

## Visual Studio Code

在很长一段时间中主要使用的 IDE，通过插件可以实现各式各样的非常强大的功能，开始使用 VS Code 是用他来写 HTML，CSS和JavaScript，之后不管是写Python，Cpp还是用各种各样的框架都用它来写，作为一款代码编辑器，VS Code基本实现了编辑器的格式统一，导致后来的各种代码编辑器以及近年诞生的AI Coding工具，几乎都仿照他的格式，作为一款 IDE，他有着非常强大的功能，也可以通过他非常便捷的实现很多git相关的操作。

但是其对初学者并不十分友好，主要有几个原因：大量功能靠插件实现，以及需要配置一些环境变量，以终端作为应用的主要运行方式（尽管也可以用点击按钮的方式去启动，但其实点击按钮这种方式本身就不能应对各种情况的运行）。这使得新用户使用起来可能比较痛苦。

## HBuilderX

我在使用uni-app进行小程序开发的时候用到了他，作为一款代码编辑器，设计感比较好，比较护眼，字体等内容设计的也比较好，有利于身心健康，结构基本仿照 VS Code，所以没什么迁移成本，但功能不如 VS Code，不建议作为主力IDE，但推荐在部分单一用途下使用，比如写个小程序这种事情，用起来还是非常舒服的。

## 微信开发者工具

似乎想要跑微信的小程序就必须使用他。

## DevEco Studio

编写鸿蒙应用的时候使用过，设计和 Android Studio 非常像，没有什么区别，并且内置的大模型还是比较好用的。

## Vim

我在Linux上的主流编辑器之一，最开始在Linux进行代码编辑的时候就常常使用他，但学习难度偏高，需要大量的命令行操作，于是我后来也迁移到了使用VSCode进行代码编辑。

如果不希望在Linux设备上使用VS Code，可以考虑在自己的Windows或者Mac上用VS Code直接通过ssh的手段打开Linux上的文件。

PS：如果你在尝试进行SSH连接的情况下发现对应的Linux设备可能处于比较严格的Security环境下，或者你不具备权限直接进行连接，那么可以查看是否Linux设备上本身可以拉取到VS Code的安装包。

## Notepad

老生常谈的代码编辑器，应对在各种极端情况下的代码编辑工作。

## Notepad++

Notepad的扩展版，增加了不少的功能，使用体验比较好。
